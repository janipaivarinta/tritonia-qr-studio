## 1. Purpose and Scope

This document provides a formal declaration of the use of generative artificial intelligence (AI) in the development of QR Studio.

The purpose of this statement is to ensure transparency regarding AI-assisted software development, distinguish human contributions from AI-generated content, and establish responsibility for the published software.

This declaration accompanies the publicly available source code and is intended to support research transparency, software citation, institutional research information reporting, and long-term archival through services such as GitHub and Zenodo.

## 2. Software Description

QR Studio is a web-based application designed to generate and export QR codes.

The application provides configurable QR code generation, including output dimensions, colors, background transparency, and downloadable file formats.

The software was developed in the context of professional duties at a university to support digital services and improve workflows for colleagues and other users.

The development was initiated and directed by the human developer, with generative AI used extensively during implementation.

## 3. Declaration of AI Use

Generative AI was substantially used throughout the software development process.

**AI system information:**

- Provider: OpenAI
- System: ChatGPT
- Model: GPT-6 Instant
- Primary purpose: AI-assisted software development
- Development approach: Human-directed, AI-assisted implementation

The AI system contributed to the generation and revision of source code, identification and resolution of technical problems, implementation guidance, and preparation of supporting documentation.

A substantial proportion of the application's source code was generated or modified with AI assistance.

The developer does not claim that the complete source code was manually written.

The identification of the AI model is based on the developer's declaration. This document does not constitute independent verification of the model used in every development interaction.

## 4. Human Contributions and Oversight

The human developer retained responsibility for the development process and the resulting software.

Human contributions included:

- Identification of the practical need for the application.
- Definition of functional requirements and intended use.
- Selection of the application architecture, technologies, and deployment environment.
- Direction and iterative refinement of AI-generated implementations.
- Evaluation of proposed technical solutions.
- Execution of functional tests and troubleshooting.
- Configuration and deployment in the intended server environment.
- Decisions regarding software publication, licensing, and maintenance.

The developer exercised human judgment when evaluating AI-generated outputs and determining whether proposed implementations were suitable for inclusion in the application.

AI-generated content was not treated as inherently correct or reliable.

## 6. Verification, Testing and Limitations

AI-generated source code was incorporated into the software development workflow under human supervision.

The application was subjected to functional testing and troubleshooting during development and deployment.

Testing activities included verification of QR code generation, output formats, application configuration, and operation within the intended server environment.

These activities do not constitute an independent security audit, formal software verification, or certification of compliance with any particular security standard.

Generative AI systems may produce incorrect, insecure, inefficient, or otherwise unsuitable source code.

Consequently, the use of AI does not eliminate the need for ongoing maintenance, testing, security assessment, and human review.
